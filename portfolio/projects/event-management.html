Event Management System

A backend-focused event management application designed to manage events, users, registrations and related data through RESTful APIs.

Java Spring Boot MySQL REST API Postman

Project Overview

The Event Management System is a backend-focused application built to practice designing and implementing RESTful APIs for a real-world domain: events, users and registrations.

Problem

Managing events, attendee registrations and related records requires a structured backend that can reliably create, read, update and delete data while exposing that functionality through clean APIs.

Solution

Built a Spring Boot backend exposing REST endpoints for events, users and registrations, backed by a MySQL database, with endpoints tested and verified using Postman.

Technology

Java Spring Boot MySQL REST API Postman

Key Functionality

  • REST API endpoints for managing events and registrations.
  • Database-driven CRUD operations using MySQL.
  • API request/response validation and testing with Postman.
